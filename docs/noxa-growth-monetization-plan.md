# NOXA 成長＆マネタイズ戦略（ドラフト v0.1 / 2026-07-26）

> このメモは 2026-07-26 の壁打ちで収束した方針をまとめたドラフト。最終判断は egshugy。
> 参考にした資料: X @MakeAI_CEO「デジタル事業承継レスキュー」（コードでなく“属人化した業務ルールの発掘・仕様化・引き継ぎ”に価値がある、という論）。

## 0. コアの発想（何を売るか）
- **NOXA = 夜の街の「ID＋データの背骨（spine）」。**
- **楔（新規案内パネル・CRM）は無料のトロイの木馬**＝背骨とネットワークを取りに行く道具。
- **お金は“上を流れるもの”から取る**（AIカスタマイズ・求人・会員特典・広告）。
- 各プロダクトは元々 NOXA ベース（noxa=店舗運営＋ハブ / yorulog=夜職CRM / nomishugy=消費者マーケット＋求人）。Firebase 共有・rules 正本は noxa。

## 1. 市場の現実（裏取り済み）
- 店舗運営POS＝ tasteck/夜レジ/CLUB NAVI/イロハ 等 **8社以上の業界特化 incumbent**（¥5,000〜29,800/月・本指名/同伴/アフター標準実装）。
- 個人CRM＝ クッキー（3万DL・業界人監修）/パピマネ 等の**先行者あり**。
- → どちらもレッドオーシャン。**唯一まだ薄いのは「AIネイティブ」と「無料での業界標準化」**。ここが勝ち筋。

## 2. フェーズ設計（ソロが焼き切れない配列）

### Phase 0（前提・今すぐ）
- **production 統合**：未マージ 74(noxa)/40(nomishugy)/71(yorulog) コミットを main へ。**標準になる基盤は“本番・統合済み・落ちない”必要**。黒箱ブランチのままでは標準化できない。
- **同意・利用目的の設計**（信用は後付け不可。無料配布の“前”に）:
  - 利用目的に「関連するオファー/特典・**自社媒体内の広告配信**・求人マッチング」を明記。
  - **第三者へ個人データを売らない/渡さない**を明文化（＝データ外販は永久にやらない）。
  - 「期間限定無料 → 正式版以降サブスク＆無料枠に広告」を**書面（利用規約/導入時の一筆）で事前告知**。

### Phase 1（land-grab＝今の最優先）
- **無料・広告なし・クリーン**。コネでゴリゴリ配布。**優先＝ユーザー密度＋コミュニティ**（ネットワーク効果）。
- 楔＝**新規案内パネル**（非クリティカル・数店舗の導入実績あり）。**無料はこの非クリティカル面に固定**（レジ本体を無料で背負わない）。
- **創業導入店は“永久特典”で握る**（永久広告なし/価格ロック等）＝伝道師＋社会的証明。
- データ堀：**キャストの移籍しても持ち運べるプロフィール＋顧客/売上履歴**を NOXA に蓄積（移籍が伝播ループになる）。

### Phase 2（サブスク解禁）
- **有料の主役＝AIカスタマイズ・プラン**（＝“難所”に課金・本命）:
  - 各店バラバラの料金体系（セット/本指名/場内/同伴/アフター/延長/ボトル/歩合/税端数…）を**AIが自然言語/既存Excelから構成・変更追従**。
  - **money はAIに確定させない**：AI下書き→**サンプル会計で検証提示**→店長承認→反映（ゴールデンマスター検証を“信用機能”に）。
  - 一括設定料でなく**「変わり続ける料金を追従し続ける」でサブスク化**。
  - **広告オフはこのプランに同梱**（単独の“広告消し”では売らない）。
- **無料枠に広告/会員特典を投入**（自給自足＋転換nudge＋直接収益の三役）:
  - **land-grab 中は入れない。サブスク解禁と同時に投入。創業店は grandfather（広告なし）。**
  - 形は **バナーCPMでなく成果報酬/提携送客**、**「広告」でなく「会員特典/提携オファー」**（値踏み感→特典感に反転）。
  - 面の規律：**消費者面(nomishugy)は通常広告OK / プロ用面はネイティブ・軽く**。業務ワークフローを汚さない。

### Phase 3（本命回収・密度がついてから）
- **求人マッチング**（夜職最大の金脈・nomishugy に求人板が既存）＝キャスト↔店の第一者マッチング（成果報酬）。
- 供給業者マーケット（酒/ドレス/美容/送迎/税理士…）、匿名・集計ベンチマーク。

## 3. 回収レバー一覧（もう増やさない・選択と順番の問題）
| レバー | 役割 | 投入時期 |
|---|---|---|
| ① AIカスタマイズ・プラン | 難所に課金・高粗利・本命サブスク | Phase 2（**回収1本目 候補**） |
| ② 求人マッチング | 夜職最大の金脈・既存求人板 | Phase 3 |
| ③ 会員特典/提携オファー | ニッチ精度を成果報酬で | Phase 2〜 |

## 4. 赤線（越えると信用/事業が壊れる）
- **個人データの外部提供/外販はしない**（合法・違法以前に標準化戦略を自壊させる）。
- **略奪的ターゲティングをしない**（例：金の無いホストにキャッシング/消費者金融）。
- **規制業種の広告表現**（美容医療/整形＝医療広告ガイドライン、貸金＝貸金業広告）は専門家確認。
- **mission-critical なレジ本体を無料で背負わない**（土曜23時に落ちてソロが即死）。
- **プロ用ワークフローを広告で汚さない**（land-grab のクリーンさ＝標準の第一印象）。
- money/税務/本番停止/rules緩和/データ削除は**人間ゲート**（資料§13）。

## 5. 生死を分ける3問（正直に答えられるか）
1. **回収の線**：「無料→◯◯で課金」の◯◯を、店/キャストが**実際に払う**と1件でも実証できるか？
2. **ネットワーク価値**：2店目・10店目が増えるほど既存店の価値が上がる仕組みは何か？
3. **ソロ耐久**：無料が50店に増えても1人で捌けるか？（＝無料面を非クリティカル＆セルフサーブに固定）
